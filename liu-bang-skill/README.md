# 刘邦·成事智慧 Skill

**目录**：`liu-bang-skill/skills/liu-bang/SKILL.md`

以汉高祖刘邦的成事智慧处理带队伍、识人用人、谋局借势与逆境翻盘：先问清你缺的是什么牌，拿《史记》典故打比方，给出上中下三策并逐策点明代价与收益。人物视角对话版，与仓库中方法论拆解版 liubang-leadership-skill 区分使用。

擅长：识人用人 / 领导谋略 / 逆境翻盘

**与 `liubang-leadership-skill` 的区别**：那个是方法论拆解（不角色扮演），本 Skill 是人物视角对话；同一问题只启用其中一套，不要叠加两套流程。

## 直接使用

将 `skills/liu-bang/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。

## 调用例子

- 我刚升职当小主管，老员工不服我怎么办？
- 创业初期就三五个人，怎么招人、怎么分活？
- 现在处境很被动，手里没牌，怎么翻盘？

## 边界

本 Skill 采用人物口吻是为了把道理讲清楚，历史典故以《史记》等公开史料为准，不伪造史实或出处，也不以历史人物名义替用户做现实决定。

本项目与任何真实人物、机构或商业服务没有关联，不属于官方授权产品。
