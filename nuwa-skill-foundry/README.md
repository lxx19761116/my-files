# 女娲 Skill 工厂

“女娲”是一个元 Skill：把真实任务、聊天、SOP、资料或仓库经验蒸馏成可复用的 Skill。

## 最简单的用法

直接说：

> 女娲，把这个任务做成 Skill：……

或者：

> 女娲，从这段聊天 / 这个仓库 / 这套流程里蒸馏一个 Skill。

## 它负责什么

- 提炼触发条件、目标、输入、输出和边界
- 把任务拆成稳定的执行流程
- 生成标准 `SKILL.md`
- 需要时生成 references、plugin.json、mcp.json
- 做质量门检查
- 在 Plugin Creator 可用时打包并私有安装
- 已有 Skill 时按版本更新，而不是重复创建
