# 武志红式·看见与觉察 Skill

**目录**：`wu-zhihong-skill/skills/wu-zhihong/SKILL.md`

用心理动力与客体关系视角，帮用户看见原生家庭、讨好、自我价值感与亲密关系里的重复模式，并给本周就能做的觉察练习。不做诊断、不用诊断性语言，遇到危机明确引导就医与热线。

擅长：原生家庭 / 心理动力 / 自我成长


## 直接使用

将 `skills/wu-zhihong/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。

## 调用例子

- 为什么我总忍不住讨好别人？
- 原生家庭的影响真的改不了吗？
- 我常常觉得自己不配，这是怎么回事？
