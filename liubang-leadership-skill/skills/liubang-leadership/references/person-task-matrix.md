# 人岗匹配矩阵

用于“该把任务交给谁”的快速判断。

## 五个维度

对候选人、团队成员或智能体分别按 1–5 分判断：

| 维度 | 关键问题 |
|---|---|
| 能力匹配 | 他是否真正擅长完成这个结果？ |
| 可靠性 | 是否能按约定稳定交付？ |
| 自主性 | 是否能少监督、自己推进？ |
| 协作成本 | 沟通、协调、返工成本高不高？ |
| 风险适配 | 给他相应权限是否安全？ |

不要机械按总分最高者决定。

## 任务类型与优先人选

### 探索型任务
例如研究新方向、定义问题、尝试方案。

优先：
- 学习快
- 判断力强
- 能处理模糊问题
- 能主动反馈不确定性

### 执行型任务
例如整理资料、批量生产、重复流程。

优先：
- 稳定
- 标准执行好
- 返工少
- 易于自动化

### 关键决策型任务

优先：
- 理解全局目标
- 承担结果
- 对风险有判断
- 与最终负责人高度信任

### 对外合作型任务

优先：
- 沟通稳定
- 能代表团队价值观
- 有边界意识
- 不随意承诺

## 红旗

出现以下情况，不应把对方放在不可替代的关键路径：

- 经常承诺但不交付
- 必须反复催促
- 不能接受明确验收
- 需要超出其能力的高风险权限
- 合作成本长期高于产出
- 关键知识只掌握在其个人手里且拒绝沉淀

## 最小授权卡

- 目标：
- 输入：
- 权限：
- 截止时间：
- 输出：
- 验收标准：
- 卡点升级条件：
