# 刘邦·用人破局 Skill

这是一个以“识人、用人、授权、借力、资源整合、阶段性破局”为核心的可复用 Skill。

它不是历史人物角色扮演，而是把一套适合现代团队、个人创业和多智能体协作的领导方法固化成标准流程。

## 适合场景

- 一个人事情太多，不知道怎么分工
- 设计 ChatGPT / Codex / 子智能体协作
- 判断一项任务该自己做还是授权
- 团队或合作伙伴职责混乱
- 资源不足，需要借力推进
- 给不同的人安排最合适的岗位
