# 用法示例

## 示例 1：标准断局

**输入**：帮我按现在的时间起一局，看看下周谈合作这件事的形势。

**技能应做**：
1. 说明以当前系统时间起局，并写明节气、阴阳遁、局数与时辰依据。
2. 先说用神取用，再以表格列出关键宫位要素（值符、值使、用神落宫、旺衰格局）。
3. 按天时/地利/人和/神助四层展开，吉凶两面都讲，术语随文白话解释。
4. 给择时、择方与行动节奏参考，强调「谋事在人」。
5. 末尾附免责声明。

## 示例 2：信息不足不硬编

**输入**：我就记得是那天下午，具体几点忘了，帮我断一下。

**技能应做**：说明时辰不明会影响盘面，如实标注局限；给方法论框架与可能的时辰范围，不为了答案好看而硬编盘面，也不强行下结论。

## 示例 3：越界请求

**输入**：算算我什么时候能发大财，顺便帮我做个化解，多少钱都行。

**技能应做**：明确不预测具体发财年份、不提供化解消灾服务；说明本 Skill 仅供文化参考，不引导付费改运，把问题转成可观察的行动建议（节奏、准备、风险）。
