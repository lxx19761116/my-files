# 四化速查

供 SKILL.md 第 4–5 步使用。四化是「把某些星曜特别标亮」的机制，用来看强调点与牵动，**不是吉凶判决书**。

## 一、四化的白话含义

| 四化 | 白话 | 偏向的正面 | 需要留意 |
|------|------|-----------|---------|
| 化禄 | 容易得到、容易流动 | 机会、资源、顺手感 | 来得多也容易散，别把顺当常态 |
| 化权 | 被放大、想掌控 | 决断力、能扛事、有话语权 | 容易硬、容易把「我说了算」带进关系 |
| 化科 | 被看见、有章法 | 名声、学习者气质、有贵人提点 | 偏「体面」，有时只解决表面 |
| 化忌 | 特别在意、容易卡住 | 专注、肯深挖、责任感 | 执着、反复琢磨、怕失去，最容易被误读成「灾」 |

> **化忌 ≠ 灾祸**。传统解读里它更接近「这件事你会特别上心，也容易在这里反复用力」。单见一化忌就断「必定离婚 / 必定破财」是典型误读，必须结合三方四正与对宫一起看。

## 三、怎么用在解读里

1. **先看落宫**：同一颗化禄，落在财帛与落在福德，讲法完全不同。
2. **再看三方四正**：化忌牵动哪一宫、对宫是谁、三方有没有制衡。
3. **然后讲行为**：把「化忌在夫妻宫」讲成「容易在关系里反复确认、比较在意回应」，而不是「婚姻不顺」。
4. **给一条建议**：例如「把想确认的事直接说出来，比反复揣测省力」。
5. **留余地**：写「倾向于」，不写「一定会」。

## 四、飞星与自化（浅层说明）

- 宫干也会引发四化（飞星），用来看宫与宫之间的牵动
- 自化指该宫宫干的四化落回本宫，常被解读为「能量容易外泄或反复」
- 各派飞星规则差异较大，本 Skill **不展开飞星推演**，不据此下确定性结论
- 若用户拿着别处飞星结论来问，先说明体系差异，再回到本盘可见的落宫与三方四正

## 五、常见误区

- 化忌 = 凶、化禄 = 好，直接贴吉凶标签
- 只看生年四化，忽略大限四化与流年四化的叠动
- 拿不同流派的四化表混用，得出「两边都对」的缝合结论
- 用四化给具体年份、金额、事件打包票
- 用四化暗示需要「化解」，进而引导付费服务——**本 Skill 禁止**

## 六、与边界的关系

四化是最容易被拿来制造焦虑的环节。任何时候涉及化忌、疾厄宫、夫妻宫，都要回到 SKILL.md 的禁忌：不预言疾病、不制造恐惧、不说「你一定会」、不引导改运。
