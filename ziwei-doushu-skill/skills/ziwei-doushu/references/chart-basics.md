# 排盘基础与口径核对

供 SKILL.md 第 1–3 步使用。本文件只讲「盘上应该有什么、哪里容易错」，不提供排盘算法，也不替代排盘工具。

## 一、必备信息

| 项目 | 说明 | 缺失时 |
|------|------|--------|
| 出生年月日 | 必须注明公历或农历 | 必须先问清，不可默认 |
| 出生时辰 | 十二时辰之一，或大致时间段 | 收敛到可能范围，做定盘校准 |
| 性别 | 影响大限顺逆行 | 不可省略 |
| 出生地 | 用于真太阳时校正 | 可选，缺则标注「未做真太阳时校正」 |
| 已知重大事件 | 2–3 个，用于定盘 | 可选，缺则标注置信度较低 |

## 三、真太阳时

钟表时间是标准时区时间，紫微斗数传统上按出生地经度换算真太阳时：

- 经度时差：与东经 120° 每差 1°，约差 4 分钟；偏西则减、偏东则加
- 均时差：因地球轨道与自转轴倾斜产生，全年在约 −16 至 +16 分钟之间波动
- 是否采用真太阳时、如何采用，各流派与工具并不统一

**处理原则**：本 Skill 不自行计算。若用户提供出生地且所用工具支持真太阳时，以工具输出为准；否则在结论中标注「未做真太阳时校正，时辰接近边界时可能影响命宫」。时辰落在两个时辰交界附近（如 12:55、14:58）时尤其要提醒。

## 四、盘上应有的要素

核对清单，缺项如实列出，不要自行补齐：

1. 命宫、身宫位置
2. 五行局（水二局、木三局、金四局、土五局、火六局）
3. 十二宫的宫干与地支
4. 十四主星落宫（含空宫标注）
5. 常用辅星、煞星、杂曜
6. 生年四化（及所用天干口径）
7. 大限起运年龄与顺逆行
8. 当前大限、当前流年干支

## 五、常见流派差异

| 分歧点 | 说明 | 处理 |
|--------|------|------|
| 安星法 | 三合派、中州派、飞星派、河洛派等在星曜安放与权重上不同 | 本 Skill 以三合派为主、四化为辅，不混用不同体系 |
| 四化天干 | 庚、戊、壬等天干的四化归属各家有异 | 以排盘工具输出为准，见 `four-hua-guide.md` |
| 闰月 | 农历闰月的月数归属处理不一 | 请用户确认所用工具口径，不自行折算 |
| 晚子时 | 归当日或次日 | 同上 |
| 空宫借星 | 是否借对宫、借几颗、能量是否降阶 | 见 `palaces-guide.md`，标注为「解读习惯」而非定论 |

## 六、常见错误

- 把农历日期当公历直接输入，或反之
- 忘记注明公历/农历，导致整张盘错位
- 时辰按口语理解（「下午」≠ 固定申时），未做收敛与校准
- 闰月、节气交界（尤其立春前后）未确认口径
- 只报一个主星就下整体结论，忽略三方四正与对宫
- 把化忌直接等同于灾祸
- 为让解读自洽，反过来修改排盘结果——**禁止**

## 七、排盘工具

本 Skill 不内置算法。可用开源项目举例（仅作可用性说明，非推荐或背书）：

- `SylarLong/iztro`：TypeScript 紫微斗数排盘库，支持多语言
- `Renhuai123/ziwei-doushu`：含排盘、四化与格局知识库的开源引擎
- 其他用户自选的可靠排盘工具或现成命盘图

工具输出与用户提供的命盘不一致时，先说明差异并请用户确认采用哪一份，不擅自取舍、不拼凑两张盘。
