# 星曜速查

供 SKILL.md 第 4–5 步使用。以下是传统术数中的**性格与倾向描述**，不是事实断言、不是科学结论。解读时一律用「倾向于」「较容易」「这个组合偏向」，并先看三方四正再谈单星。

## 一、十四主星

| 主星 | 关键词 | 偏向的正面 | 需要留意 | 白话翻译 |
|------|--------|-----------|---------|---------|
| 紫微 | 统领、格局 | 有主见、能扛事、愿意负责 | 容易在意位子与面子、不喜被质疑 | 天生想当主心骨，但别把「我说了算」当默认设置 |
| 天机 | 思辨、变化 | 反应快、会拆解、善谋划 | 想太多、容易改主意、计划反复 | 脑子转得快，适合出方案，但要给决定设个截止时间 |
| 太阳 | 外放、给予 | 大方、热诚、愿意照亮别人 | 容易过度付出、忽略自己消耗 | 习惯照顾全场，记得给自己也留点电 |
| 武曲 | 执行、结果 | 果断、扛压、讲效率 | 偏硬、不太照顾感受、易急躁 | 结果导向的实干派，沟通时补一句温度就顺了 |
| 天同 | 感受、舒缓 | 好相处、包容、会享受生活 | 容易回避冲突、动力偏被动 | 脾气好、日子过得舒服，但事情得有人推一把 |
| 廉贞 | 原则、边界 | 有立场、重分寸、能守规矩 | 易较真、情绪起伏、关系里拉扯 | 心里有杆秤，别让「对错」盖过「想怎么一起过」 |
| 天府 | 稳盘、蓄积 | 稳重、会守成、擅长整合资源 | 偏保守、不轻易冒险 | 适合管盘子、守家底，突破时得主动加一点变量 |
| 太阴 | 细腻、积累 | 敏感、审美强、耐心好 | 易内耗、想得多说得少 | 感受力是优势，把想法讲出来才不会被误会 |
| 贪狼 | 兴趣、多面 | 好奇、会交际、学得快 | 兴趣太杂、易分心、想要的多 | 什么都能上手，挑一两件深耕才有复利 |
| 巨门 | 质疑、表达 | 会追问、能看出漏洞、逻辑强 | 易生疑虑、说话直、易起误会 | 天生会挑问题，把质疑说成「我想确认一下」更顺 |
| 天相 | 协调、秩序 | 公正、可靠、会居中协调 | 易受环境影响、不太爱自己拍板 | 天生的调解人，但关键时刻要练自己下结论 |
| 天梁 | 担当、庇护 | 有原则、愿意兜底、能扛责任 | 爱操心、说教感、易背别人的事 | 团队里的老大哥/大姐，记得别把别人的课题扛过来 |
| 七杀 | 决断、独立 | 敢冲、能扛硬仗、不拖泥带水 | 起伏大、耐性有限、单打独斗 | 适合打硬仗，配一个能收尾的搭档更稳 |
| 破军 | 破立、变动 | 敢推倒重来、适应力强 | 变动多、稳定性弱、易一刀切 | 擅长开新局，但「先修还是先换」值得多想一步 |

## 二、常用辅星与煞星（速记）

| 类别 | 星曜 | 白话倾向 |
|------|------|---------|
| 助力 | 左辅、右弼 | 有人帮、适合协作 |
| 文书 | 文昌、文曲 | 学习、表达、文书与审美相关 |
| 贵人 | 天魁、天钺 | 容易遇到提携或关键引荐 |
| 资源 | 禄存、天马 | 积累与流动、变动中的机会 |
| 阻力 | 擎羊、陀罗 | 摩擦、拖延、反复打磨 |
| 波动 | 火星、铃星 | 急、突发、节奏被打乱 |
| 空耗 | 地空、地劫 | 想法多但落地难、易有落差感 |

> 煞星不等于凶、吉星不等于好。传统解读里「有制、有对照、有位置」比名称更重要；单看一颗煞星就下负面结论属于典型误读。

## 三、解读纪律

1. **先组合、后单星**：命宫主星 + 对宫 + 三方四正一起看，才构成基调。
2. **同类不叠加堆形容词**：三颗星都写「聪明」没有信息量，要写它们怎么互相拉扯。
3. **正面先行**：每颗星先说它擅长什么，再说容易卡在哪。
4. **翻成行为**：把「巨门」翻成「习惯先质疑」，而不是「命带口舌」。
5. **空宫不硬填**：空宫按 `palaces-guide.md` 处理，标注借星是解读习惯而非定论。
6. **不编星曜**：盘上没有的星，不因为解读需要而补进去。

## 四、常见误区

- 把「杀破狼」当成「命不好」的标签——它只是变动性偏高的一类结构
- 把「机月同梁」直接等同于「适合当公务员」——那是职业刻板印象，不是盘面结论
- 用单颗主星给整个人下定义
- 把辅煞星名称当成吉凶判决
- 引用「古书说」却不给出具体出处——本 Skill 禁止编造原文
