# 十二宫与三方四正

供 SKILL.md 第 4–5 步使用。宫位是**看问题的角度**，不是「人生被切成十二块」的断言。

## 一、十二宫含义速查

| 宫 | 主要看什么 | 白话问法 |
|----|-----------|---------|
| 命宫 | 性格底层、行事底色、自我认同 | 我大概是个什么样的人 |
| 兄弟宫 | 同辈、合作与手足关系 | 我和平辈怎么相处 |
| 夫妻宫 | 亲密关系模式、伴侣相处 | 我在关系里容易怎样 |
| 子女宫 | 晚辈、创作与投入的事 | 我怎么带人 / 怎么对待自己孵出来的东西 |
| 财帛宫 | 钱的来去方式、风险偏好 | 钱怎么来、怎么留 |
| 疾厄宫 | 身体节奏、压力反应 | 我累了会先表现在哪 |
| 迁移宫 | 外部环境、外出与变动 | 出了熟悉的环境我会怎样 |
| 交友宫（奴仆） | 朋友、人脉与协作圈 | 我身边都是些什么人 |
| 官禄宫 | 事业路线、工作方式、担当 | 我适合怎么做事 |
| 田宅宫 | 家、根基、积累与安稳感 | 什么让我觉得稳 |
| 福德宫 | 精神趣味、享受方式、内在消耗 | 我怎么给自己充电 |
| 父母宫 | 长辈、来处与早期环境 | 早年的环境给我留下什么 |

> 疾厄宫只谈作息、压力与节奏倾向，**不做疾病判断、不替代就医**。

## 二、三方四正

看任何一宫，至少同时看四个位置：

```
        本宫的三方（相隔四宫）
              │
   三方之一 ── 本宫 ── 三方之二
              │
           对宫（正照，相隔六宫）
```

| 本宫 | 三方（财帛 / 官禄 / 迁移 举例） | 对宫 |
|------|------------------------------|------|
| 命宫 | 财帛宫、官禄宫、迁移宫 | 迁移宫 |
| 夫妻宫 | 夫妻宫的三方（迁移、福德等按实际盘位） | 官禄宫 |
| 财帛宫 | 命宫、官禄、福德等按实际盘位 | 福德宫 |
| 官禄宫 | 命宫、财帛等按实际盘位 | 夫妻宫 |

> 上表为常见示意，实际三方以盘上相隔四宫的位置为准。**先按盘面确认，不要凭记忆套表。**

**为什么必须看**：单宫像是只听一个人说话；三方四正是把同一件事的几个侧面一起摆上桌。命宫再好，三方皆空或煞重，解读的基调就要改。

## 三、问事选宫（先看哪几宫）

| 用户问 | 主看 | 必须合看 |
|--------|------|---------|
| 性格 / 自我 | 命宫 | 身宫、福德宫、迁移宫、三方四正 |
| 事业 | 官禄宫 | 命宫、财帛宫、迁移宫、对宫夫妻宫 |
| 财运 | 财帛宫 | 命宫、官禄宫、福德宫、田宅宫 |
| 感情 | 夫妻宫 | 命宫、迁移宫、福德宫、对宫官禄宫 |
| 今年运势 | 流年命宫 | 当前大限、生年四化、流年四化 |
| 家庭 / 住处 | 田宅宫 | 父母宫、子女宫 |
| 压力与状态 | 疾厄宫 | 福德宫、命宫 |

## 四、空宫处理

- 空宫指本宫无十四主星，**不等于「这一宫空白 / 这一生没有」**
- 常见做法是借对宫主星参照，并把能量视为降阶（有说法取七成、见煞再降），但这是**解读习惯，不是定论**
- 借星时必须写明「借对宫参照」，并同时说明对宫的实际情况
- 不为了让解读好看，硬把别宫的星搬进来充数

## 五、大限与流年

- **大限**：约十年一段的阶段性课题，顺逆行由性别与命宫阴阳等规则决定，以排盘工具输出为准
- **流年**：当年的干支与四化牵动，用来谈节奏与准备方向
- 谈流年只说「倾向 / 值得留意」，不写「某年必发生某事」
- 大限与流年结论若与生年结构冲突，先说明冲突，不强行统一

## 六、常见误区

- 只看本宫一颗星就下结论
- 把三方四正当成固定表格背，而不按实际盘位核对
- 把宫名当吉凶（「夫妻宫不好 = 婚姻完了」）
- 空宫当成「没有」，或反过来借星借到满盘皆星
- 用疾厄宫做健康预测
- 用流年给具体事件、金额、年份打包票
