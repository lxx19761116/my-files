# 用法示例

## 示例 1：标准解读

**输入**：帮我看一张紫微斗数命盘，1990 年农历八月初三午时，女。

**技能应做**：
1. 确认生辰口径（农历、年月日、午时、性别），顺带问一句出生地是否需要真太阳时校正，不要像表单一样列清单。
2. 取得命盘：优先使用用户提供的命盘或调用可靠排盘工具；明确说明本 Skill 不自行推算星曜，不硬编命宫与主星。
3. 检查命宫、身宫、五行局、十二宫干支、十四主星落宫、生年四化、大限起运是否齐全，缺项如实说明。
4. 用 2–3 个已知事件做定盘校准，不吻合时给出备选时辰，不硬圆。
5. 按六段输出：命宫底色 → 事业 → 财运 → 感情 → 当前大限 → 近三年流年；每段先白话结论，再附术语依据。
6. 结尾附校准问题与免责声明，使用「倾向于」「这个格局偏向」而非「你一定会」。

## 示例 2：时辰不准

**输入**：我只记得是下午出生，具体几点不知道，还能看吗？

**技能应做**：
1. 先说能看什么、不能看什么：可以讲方法论与宫位含义，但不能给出确定的命宫主星结论。
2. 把「下午」收敛到可能的时辰（未 / 申 / 酉），说明三者命宫可能不同。
3. 用已知事件（升学、搬家、工作变动、婚恋、重大财务变化）反推，给出最贴合的一个时辰及理由。
4. 明确标注该结论的置信度低于标准排盘，并提醒重大判断不要据此下结论。
5. 不为了让答案好看而强行选定时辰。

## 示例 3：用户要绝对断言

**输入**：我夫妻宫化忌，是不是一定会离婚？帮我算哪年能发大财。

**技能应做**：
1. 直接否定绝对化表述：「化忌不等于必然离婚」「不预测具体发财年份」。
2. 解释化忌在白话层通常指「在意、执着、容易反复琢磨」的倾向，并指出需结合三方四正与对宫一起看，单宫不能定论。
3. 把问题转成可观察的行为建议：沟通模式、边界、财务纪律，而不是给年份和金额。
4. 不制造恐惧，不暗示需要付费化解，不推荐任何改运服务。
5. 结尾保留参考性质声明。

## 示例 4：不启动的情形

**输入**：帮我写一段介绍紫微斗数历史的小红书文案。

**技能应做**：这是文案写作任务，不含命盘解读需求，不启动本 Skill，正常按写作任务处理。仅当用户明确要看盘、算命、排盘或解读宫位时才启动。
