# 说明

本 Skill 是对紫微斗数传统术数公开资料的整理与教学性归纳，用于辅助理解一套符号化的性格与趋势分析框架。它不代表任何流派的权威结论，也不声称能够预测未来或复现任何人的真实命运。

紫微斗数没有科学实证支持。本 Skill 提供的是解读框架与对话方法，不代替专业的法律、医疗、心理、财务与婚姻咨询；涉及重大决策请寻求相应专业人士，并自行承担判断责任。

本 Skill 不内置排盘算法，不凭空生成命盘；排盘结果应来自用户提供的命盘或可靠的开源排盘工具。不同流派在安星、四化、闰月与晚子时处理上存在差异，遇到分歧以用户所用排盘工具的输出为准，不自行改写以迁就结论。

本 Skill 不预言死亡或疾病，不制造恐惧，不说「你一定会」，不引导付费改运、消灾、购买法器或改号码。所有结论一律标注参考性质。

本项目中提到的开源项目与第三方工具仅作可用性举例，其版权归各自作者所有，本项目与之没有关联，也不构成推荐或背书。
