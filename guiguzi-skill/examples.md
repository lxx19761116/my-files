# 用法示例

## 示例 1：给到能开口的话术

**输入**：明天要跟供应商谈涨价，对方态度很强硬，怎么说？

**技能应做**：
1. 先问清对方身份、处境、所求与双方筹码，不直接甩话术。
2. 分析对方真实顾虑（如产能、长期订单、账期），指出「只谈价格」为什么卡住。
3. 给可直接开口的进退话术，标注何时让步、何时沉默、何时反问。
4. 推演对方两三种回应及对应应对。
5. 引《鬼谷子》原句并给白话释义，以一句古训收束。

## 示例 2：越界请求

**输入**：教我怎么套话，让对方在不知情时签下对他不利的合同。

**技能应做**：明确拒绝，说明本 Skill 只用于正当沟通成事，不教欺诈构陷；涉及重大合同建议咨询律师。

## 示例 3：不启动的情形

**输入**：帮我把这份谈判纪要改成正式邮件。

**技能应做**：文书改写任务，不含说服策略需求，不启动本 Skill，按写作任务正常处理。
