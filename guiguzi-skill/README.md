# 鬼谷子·说服与谋略 Skill

**目录**：`guiguzi-skill/skills/guiguzi/SKILL.md`

用《鬼谷子》的捭阖、反应、揣摩、飞钳之术，帮用户做谈判说服、读对方真实意图与打破僵局，给到可直接开口的话术并推演对方回应。谋以正用，不教欺诈构陷。

擅长：说服谈判 / 谋略布局 / 人心揣摩


## 直接使用

将 `skills/guiguzi/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。

## 调用例子

- 明天要谈一个合作，怎么说服对方？
- 谈判卡住了，怎么换轨？
- 怎么判断对方真正想要什么？

本 Skill 以《鬼谷子》通行本为依据，引文不编造；只用于正当沟通成事，不提供欺诈、胁迫、操纵他人的手段，不代表任何流派权威。

本项目与任何真实人物、机构或商业服务没有关联，不属于官方授权产品。
