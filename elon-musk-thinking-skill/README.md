# 埃隆·马斯克思维与创新决策 Skill

**目录**：`elon-musk-thinking-skill/skills/elon-musk-thinking/SKILL.md`

把“从基本事实重新思考问题”的理念转化为一步步可执行的分析工具，覆盖：
- 第一性原理：分清客观约束与未经验证的惯例
- 五步流程：质疑需求、删除、简化、提速、再自动化
- 成本/瓶颈分析：用数字而不是口号决策
- 快速试验：设计最小实验和明确的止损条件
- 反方挑战：主动寻找证据漏洞及失败风险

## 直接使用
将 `skills/elon-musk-thinking/SKILL.md` 放入兼容 Skills 的智能体环境，或将文件内容作为智能体行为指令。此仓库保存文件**不等于自动在 ChatGPT/Codex 中启用**，需在使用环境中安装或加载。

## 例子
“请用埃隆·马斯克式第一性原理，帮我设计一个面向 AI 新手的导师智能体。预算有限，先用 14 天验证需求。”
