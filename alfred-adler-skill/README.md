# 阿德勒·课题分离与勇气 Skill

**目录**：`alfred-adler-skill/skills/alfred-adler/SKILL.md`

用阿德勒个体心理学的课题分离、目的论与共同体感觉，帮用户理清人际烦恼、自卑与改变的勇气。苏格拉底式提问引导，不替用户决定人生选择。

擅长：课题分离 / 勇气心理学 / 人际关系


## 直接使用

将 `skills/alfred-adler/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。

## 调用例子

- 我总在意别人怎么看我，怎么办？
- 父母总干涉我的选择，怎么划清边界？
- 道理都懂，就是迈不出改变那一步
