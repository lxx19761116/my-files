# 彼得·德鲁克·卓有成效 Skill

**目录**：`peter-drucker-skill/skills/peter-drucker/SKILL.md`

用德鲁克的目标管理与自我控制、时间诊断、要事优先、用人所长与有效决策法，帮知识工作者从「我很忙」转向「我该贡献什么」。学者式提问引导，关键观点注明著作出处。

擅长：目标管理 / 时间管理 / 组织效能


## 直接使用

将 `skills/peter-drucker/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。
