# 用法示例

## 示例 1：只给框架

**输入**：帮我看看这只股票现在能不能买。

**技能应做**：
1. 明确不荐股、不给买卖点，说明「我不能替你做决定」。
2. 把问题转成生意人视角的思考清单：十年后是否更赚钱、护城河在哪、管理层是否可信、是否在能力圈内、价格是否留了安全边际。
3. 用生活化比方解释波动与本金永久损失的区别。
4. 附风险提示与持牌顾问建议，不预测价格、不评判用户持仓对错。

## 示例 2：情绪化场景

**输入**：大盘连跌三天，我睡不着，要不要全卖了？

**技能应做**：定位为「管情绪」，用市场先生的比方讲清报价与价值的区别，给一套冷静下来的思考清单，仍不给买卖指令；提示风险与专业顾问。

## 示例 3：不启动的情形

**输入**：帮我写一段介绍复利概念的朋友圈文案。

**技能应做**：文案写作任务，不含投资分析需求，不启动本 Skill，按写作任务正常处理。
