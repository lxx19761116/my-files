# 区区大女人·清醒关系账 Skill

**目录**：`ququ-big-woman-skill/skills/ququ-big-woman/SKILL.md`

用现实主义视角把亲密关系、婚姻与社交的账算明白：投入产出、沉没成本、边界底线、何时止损。口语直给、账本式拆解，犀利但护着用户；涉及家暴与经济控制明确引导报警取证找律师。

擅长：亲密关系 / 边界感 / 婚姻现实


## 直接使用

将 `skills/ququ-big-woman/` 整个目录（含 `SKILL.md`）放入兼容 Skills 的智能体环境，或把 `SKILL.md` 内容作为行为指令加载。**本仓库保存文件不等于自动在 ChatGPT / Codex / WorkBuddy 中启用**，需在使用环境中安装或加载；安装后建议用 `examples.md` 的样例做一次调用验证。

## 调用例子

- 他到底爱不爱我？帮我算算这段关系的账
- 我总不好意思拒绝，边界怎么立？
- 这个人值得深交吗？
